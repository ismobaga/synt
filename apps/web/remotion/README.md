# Remotion support

This folder contains a starter Remotion composition for Synt.

## Commands

```bash
cd apps/web
npm install
npm run remotion:studio
npm run remotion:render
```

## Entry points

- `index.ts` — registers the Remotion root
- `Root.tsx` — defines the available composition(s)
- `SyntProgrammaticVideo.tsx` — sample React-driven video layout
- `sample-props.ts` — starter props you can replace with your timeline manifest
